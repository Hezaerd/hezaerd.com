# Vocabulaire Portal (operator)

Termes du `CONTEXT.md` Portal — utilise-les tels quels :

| Terme | Usage |
|-------|--------|
| **Portal** | App signée `/`, pas site marketing |
| **Operator** | Hezaerd / staff — pas « admin » en UI |
| **Client** | Org/personne collaborant via Portal |
| **Client Desk** | Hub operator `/op/clients/{slug}` |
| **Waiting on Client** | Travail ouvert needing réponse Client (facture impayée, file request) |
| **Waiting on Operator** | Follow-up practice-side (ex. brouillon facture) |
| **Practice Cockpit** | Tuiles Operator Home |
| **Insights** | Area Statistiques (Feature) — pas « Analytics » côté Client |
| **linked site** | Site public piloté depuis Desk Site |
| **Feature** | Gate operator pour Areas au-delà du Core |

Ne pas confondre Desk sections (operator) et Areas (Client Workspace).
